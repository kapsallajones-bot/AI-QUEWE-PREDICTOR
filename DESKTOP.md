# Meridian Bank Queue Intelligence — Desktop App Guide

This project is a full TanStack Start (React + TypeScript + Tailwind) app that is wrapped as a
desktop application with Electron, including a branded splash window.

## 1. Getting the code into Visual Studio Code

You have three ways to get every file. Option A is the easiest and always complete.

### Option A — Download the project (recommended)

1. In Lovable, open the top-right menu and choose **GitHub → Connect to GitHub** (or **Download ZIP** if available).
2. If you used GitHub: copy the repository URL, then in VS Code press `Ctrl+Shift+P` → **Git: Clone** → paste the URL → pick a folder.
3. If you downloaded a ZIP: unzip it, then in VS Code use **File → Open Folder…** and select the unzipped folder.

### Option B — Copy file by file

1. In VS Code, create an empty folder and open it (**File → Open Folder…**).
2. In Lovable, switch to the **Code** view (the file browser you are looking at now).
3. For every file in the tree: open it, select all (`Ctrl+A`), copy (`Ctrl+C`).
4. In VS Code create the same path (right-click in the Explorer → **New File…**, and type the
   full path like `src/routes/dashboard.tsx` — VS Code creates the folders for you), then paste
   (`Ctrl+V`) and save (`Ctrl+S`).
5. Repeat until the folder structure below matches. Do **not** copy `node_modules` — it is
   regenerated by `npm install`.

### Option C — Terminal clone

```sh
git clone <your-repository-url>
cd <repository-name>
code .
```

## 3. Run it in VS Code

Open the integrated terminal (`Ctrl+` `) and run:

```sh
npm install          # install dependencies (needs Node.js 20+)
npm run dev          # web version at http://localhost:8080
```

Recommended VS Code extensions: **ESLint**, **Prettier**, **Tailwind CSS IntelliSense**.

## 4. Run / build the desktop app (with splash screen)

Install the Electron tooling once:

```sh
npm install --save-dev electron @electron/packager
```

Add these entries to `package.json`:

```json
{
  "main": "electron/main.cjs",
  "scripts": {
    "electron:dev": "vite dev & ELECTRON_DEV=1 APP_PORT=8080 electron .",
    "electron:start": "npm run build && electron .",
    "electron:package": "npm run build && electron-packager . \"MeridianQueue\" --overwrite --out=electron-release"
  }
}
```

On Windows use two terminals instead of `&`:

```sh
# terminal 1
npm run dev
# terminal 2
set ELECTRON_DEV=1 && set APP_PORT=8080 && npx electron .
```

Then:

- `npm run electron:start` — production desktop run: splash window appears, the app server boots in
  the background, and the main window opens maximized once the app is ready.
- `npm run electron:package` — produces a distributable folder in `electron-release/`
  (add `--platform=win32 --arch=x64` for a Windows build, `--platform=darwin` for macOS).

## 5. How the splash works

`electron/main.cjs` opens a frameless 520×340 window loading `electron/splash.html` immediately at
startup. It shows the Meridian logo, an animated progress bar and rotating status messages that
match the app's blue design system. In parallel the app server is started and polled; as soon as
the main window fires `ready-to-show`, the splash is destroyed and the main window is shown. To
change the splash branding, edit the colors, title and `steps` array inside `electron/splash.html`.
