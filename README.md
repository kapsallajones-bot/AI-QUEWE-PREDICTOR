# QueueFlow Pro

1. Login Page

Design a modern desktop banking application login page. Professional blue and white color scheme with subtle gradients. Place the bank logo at the top center. Include Username and Password fields, a "Remember Me" checkbox, Login button, and Forgot Password link. Show role selection (Admin or Cashier) with radio buttons. Clean banking interface with rounded cards, minimal icons, and a secure professional appearance. Windows desktop application style.

2. Admin Dashboard

Design a modern desktop Admin Dashboard for an AI-powered bank queue management system. Include a left sidebar with Dashboard, Queue Management, Cashiers, Reports, Settings, AI Prediction, and Logout. The main dashboard displays Total Customers Today, Customers Waiting, Active Cashiers, Average Waiting Time, and Queue Efficiency as statistic cards. Add charts showing hourly customer arrivals and average service time. Display a live queue table with Queue Number, Customer Status, Assigned Cashier, Predicted Waiting Time, and Current Position. Blue and white professional banking theme.

3. Queue Management Page

Design a desktop Queue Management screen for a bank. Include a large table displaying Queue Number, Customer Name (optional), Arrival Time, Predicted Waiting Time, Current Position, Assigned Cashier, and Status (Waiting, Called, Serving, Completed). Include buttons for Add Customer, Remove Customer, Call Next, Pause Queue, and Refresh Queue. Add search and filter options at the top. Clean professional banking interface.

4. Cashier Dashboard

Design a desktop Cashier Dashboard for an AI-powered bank queue system. Show cashier profile at the top with cashier number and name. Display a large status toggle button labeled "Available" (green) and "Busy" (red). Show the current customer being served with Queue Number, Estimated Service Time, and Transaction Timer. Include buttons for Start Service, Complete Service, Skip Customer, and Call Next Customer. Display a list of upcoming customers with AI-predicted waiting times. Professional banking desktop UI.

5. Customer Ticket Generation Page

Design a desktop page where bank staff generates customer queue tickets. Include input fields for Service Type (Deposit, Withdrawal, Account Opening, Customer Service, Loan, etc.). Display an automatically generated Queue Number. Show AI Predicted Waiting Time, Estimated Serving Time, Current Customers Ahead, and Assigned Service Category. Include a large Print Ticket button. Professional receipt preview displayed on the right.

6. Printed Queue Ticket

Design a realistic thermal receipt ticket for a bank queue system. Display the bank logo at the top, Queue Number in large bold font, Service Type, Date and Time, AI Estimated Waiting Time, Number of Customers Ahead, Counter Assignment (if available), and a thank-you message. Include a QR code at the bottom. Clean black-and-white receipt style.

7. Queue Display Screen (Customer Waiting Area)

Prompt:

Design a large public display screen for a bank waiting room. Show the Current Queue Number in very large bold text. Display the Current Cashier Counter. Show Next Five Queue Numbers below. Include AI Estimated Waiting Time for waiting customers. Display the current date and time. Use a blue professional banking theme with high visibility for customers.

8. Voice Announcement Screen

Design a desktop announcement interface for a bank queue management system. Display large text saying "Now Serving". Show Queue Number B105 in very large font and Counter 3 below it. Include speaker animation and microphone icon indicating voice announcement is playing. Display announcement text: "Queue Number B105, please proceed to Counter 3." Professional banking UI with blue theme.

9. Cashier Management Page (Admin)

Design a desktop page for managing bank cashiers. Display a table containing Cashier ID, Name, Counter Number, Current Status (Available/Busy/Offline), Customers Served Today, Average Service Time, and Performance Rating. Include buttons to Add Cashier, Edit, Delete, Enable, Disable, and View Activity. Modern banking admin interface.

10. AI Prediction Dashboard

Design a futuristic desktop AI Prediction dashboard for a bank queue management system. Display machine learning analytics including Predicted Waiting Time, Queue Growth Forecast, Average Service Duration, Peak Hours, Cashier Efficiency, Customer Flow Heatmap, and AI Recommendation Cards suggesting when additional cashiers should open. Use modern charts, graphs, and blue AI-themed banking visuals.

11. Reports Page

Design a professional bank reports page. Include report filters by date, cashier, service type, and branch. Display charts showing daily customers served, average waiting time, busiest hours, cashier performance, and AI prediction accuracy. Include Export to PDF, Excel, and Print buttons.

12. System Settings Page

Design a desktop settings page for a bank queue system. Include settings for Voice Announcement, Speaker Volume, Queue Number Format, AI Prediction Settings, Ticket Printer Configuration, Database Backup, Theme Selection, User Management, and Security Settings. Professional banking interface with organized tabs and toggle switches.
